# Vultr Pocket 3.0 · Android 原生设计系统

参考 FlClash 的紧凑卡片、分组列表与柔和选中导航；沿用 Java Views。UI UX Pro Max 的 operations dashboard 查询用于状态层次和可访问性，舍弃营销落地页内容、模糊玻璃、外部字体与网页 hover 建议。

- 五个主页面：总览、服务器、订阅、费用、设置。总览首卡为账户余额和未出账；未知金额显示破折号。原始 API 账面值保留在加密缓存；显示时将账面负号转换为账户结余，再扣除未出账费用，作为剩余可用。不足时可用显示零，并单列待补金额，绝不对欠费取绝对值。
- 浅色 BG #F7F8FA / surface #FFFFFF / text #17243C / muted #56667D / blue #285CDE / success #087754。
- 深色 BG #111318 / surface #1B1E25 / text #EDF2FC / muted #B0BDD2 / blue #91B4FF / success #71E1B5。
- 卡片圆角 24dp；按钮 14dp；输入框 12dp。外边距 16dp（宽屏 32dp），卡片间隔 12dp，内容 16dp。
- 标题 24sp、金额 32sp、卡片标题 18sp、正文 15–16sp、元信息 12–14sp，中文系统字体。全局语义配色的文字对比度最低 5.00:1。
- 每卡最多两项直接操作，其余明确放入更多菜单。按钮以 PRIMARY / SECONDARY / DANGER / PLAIN 类型指定样式，不根据标题推断。
- 触控至少 48dp；小图标使用矢量 Drawable。大字体导航增加高度；长字段和大字体信息行改为上下排列。状态同时有文字，不仅靠颜色。
- 主导航有独立滚动记录；详情有返回栈和所属导航；任务通过页面 epoch 校验，旧任务不能覆盖新页面。
- 服务器每 60 秒、账户与 Cloudflare 每 5 分钟。首页退出或熄屏停止调度。旧记录标记缓存/过期；脉冲只依据新鲜云端电源状态，不代表流量或代理健康。
- 凭据只在主动编辑时出现，默认隐藏。正式 App 保留 FLAG_SECURE，预览包独立应用 ID、虚构数据且无联网权限。

布局预览：previews/redesign.html 与 previews/redesign.png。原生验收截图及检查结果位于 qa/screens；与 HTML 预览的差异以原生截图和实际 App 为准。

## 3.1 可选的服务器运行样式

仅首页服务器卡片增加可选拟物效果，其他页面继续保持 FlClash 风格。名称、IP、状态与右侧 80×64dp 运行指示器构成同一行；呼吸圆点与微型机架共用槽位。机架为缓存 Canvas 路径、金属渐变、双风扇、通风孔和电源灯。风扇每 6.4 秒匀速一圈，灯光每 2.4 秒柔和变化，纯装饰、不反映 CPU/真实转速。

设置 → 外观 → 服务器运行样式：示例预览并列，应用才保存，取消不变。ui_server_animation 取 pulse/rack，缺失或非法值使用 pulse；原 ui_motion 保留，界面改名运行效果动画。关闭动画/减少动画时保留静态造型；停机或状态失效显示灰灯。离开前台、失焦、滚出可见区域或熄屏停止循环，最高 20fps。正式 App 保留防截图，QA 图片来自独立无网络虚构包。

交互预览：previews/server-animation.html。


## 3.2.0 系统与主机标识

首页、服务器列表与两种详情页复用静态 SystemBadge：20dp 本地 Canvas 图形 + 8dp 间距 + 14sp 完整系统名。图标为装饰，不额外播报；系统文字可换行，不截断。首页标识位于名称下方，主机套餐位于通栏；右侧保留原 80×64dp 运行效果。

仅按云端 os 字段识别系统，忽略大小写，未知保留原名，缺失显示“系统待获取”。主机使用当前 /instances 来源“Vultr 云主机”和已有 plan，不推断物理型号或 CPU 品牌。Ubuntu / Debian / Windows / macOS / Fedora / Rocky / Alma / Arch 使用本地识别图形，其余已识别 Linux 使用通用企鹅；所有图标旁均显示原始系统全名。macOS 仅显示兼容，不改变现有 Ubuntu 部署能力。


## 3.2.1 Cloudflare 诊断日志

固定订阅监视卡片增加明确的诊断日志行入口；详情归属订阅导航，保留返回关系。使用现有圆角卡片、14sp 可选择正文，按最新优先展示 20 轮，复制包含全部保留的 100 轮。最近失败单独置顶，复制和清空有明确按钮，清空需确认。使用 UTC 时间、中文阶段和错误标签，网络/VPN 的观测范围同时说明。日志在本机加密保存，只允许域名、枚举错误类型、HTTP 状态及耗时，不显示原始异常或私密 URL。


## 3.3.0 创建与启动

原 80×64dp 设备视图新增橙色启动态。机架在创建态停扇、三枚等待灯顺序亮起，云端 installingbooting 时慢速风扇与等待灯；圆点使用橙色分段转环。绿色仅表示新鲜运行态。详情页共享运行组件，标明云端状态与订阅核验的区别；启动观察限前台 10 秒一次、3 分钟上限，仅 GET。减少动画或关闭动画时保留静态造型和状态文字，无虚构百分比。


## 3.4.0 服务器卡片操作

卡片主操作为开机和关机，关机使用危险色描边；登录信息、刷新状态、详情与更多采用行入口。密码区默认折叠，展开后按地址、用户名、默认协议/端口、初始密码分组；密码默认遮罩，显示/隐藏与复制有明确按钮，离开清除。大字体自然换行，无横向溢出。电源确认必须显示准确名称、IP 和实例 ID，说明中断影响和继续计费；不使用输入确认词。


## 3.4.1 直接展示登录字段

主机登录区改为默认可见的用户名、默认协议/端口和等宽明文初始密码，去除展开与显示开关；两项复制按钮和 SSH 命令行入口保留。长密码自然换行，完整可选择；空内容、读取中、读取失败分别显示明确文字。只在前台显示，返回前台自动恢复；凭据在手机以独立加密缓存保存。


## 3.4.2 重新部署确认

重装弹窗不再要求输入 reinstall。保留准确名称、IP、实例 ID 与不可恢复的磁盘清空说明，使用取消和危险色“确认重新部署”按钮；提交后禁用重复确认。


## 3.5.0 分流升级入口

固定订阅详情的“更多”菜单增加“升级当前订阅分流（保留节点）”与“恢复升级前固定订阅”。均使用按钮确认，提示保留 URL、发布后客户端刷新生效；不自动导入或切换 VPN。失败反馈采用脱敏原因，首次规则下载失败保留原配置。


## 4.0 运维控制台风（3.6.0）

参考 Vercel / Linear / Tailscale 手机版：中性灰阶 + 单一强调色，细描边代替大白卡，信息更紧凑。

- 浅色 BG #F5F6F8 / surface #FFFFFF / border #E3E6EB / soft #F0F2F5 / text #0F172A / muted #566070 / blue #2563EB / green #166534 / amber #92400E / danger #A61B1B。
- 深色 BG #0B0D10 / surface #14171C / border #262B33 / soft #1C2027 / text #E6E8EB / muted #9AA3AF / blue #6EA8FE / green #4ADE80 / amber #FBBF24 / danger #F87171。
- 所有文字与状态胶囊（12%/16% 同色底）对比度 ≥ 4.5:1，muted ≥ 5:1。
- 卡片圆角 12dp + 1px 描边，间距 10dp；按钮、输入框圆角 8dp，触控仍 ≥ 48dp。卡片标题 15sp medium，页面标题 22sp medium。
- 按钮：PRIMARY 实心强调色，每张卡最多一个；SECONDARY 白底描边 + 正文色；DANGER 描边 + 红字；PLAIN 文字按钮（“更多”“管理”等）。

- 横向按钮行不设垂直居中且关闭基线对齐，避免带上边距的按钮被裁切。


## 3.7.0 刷新策略

- 读写分两条通道。写通道 `task()`：会改动云端或本机关键数据的操作（开关机、新建/重装/删除、发布、编辑凭据），一次一个，顶部进度条提示，执行期间持有数据锁。读通道 `load(key,…)`：所有刷新，在 `Manager.NET`（3 线程）并行，不锁按钮、不显示顶部进度条；同一 key 进行中会合并；失败只在页面内提示“更新失败 · 保留缓存”。
- 数据写入统一经 `Manager.commit()` 或 `synchronized(manager)`；网络请求在锁外。界面线程永不等锁。
- 分级刷新（`Refresher`）：服务器列表 60 秒（仅总览/服务器页在前台且开启首页自动更新）、余额 5 分钟、Cloudflare 固定订阅 15 分钟、完整账单 6 小时（加密缓存 `costs_cache`，重启后仍有效）。打开页面先显示缓存，只拉过期资源；顶部刷新强制刷新本页资源。订阅页顶部刷新只做本地整理 + 固定订阅检查，“检查全部订阅”在「管理」菜单后台进行。
- 结果 250ms 内合并为一次重绘，数据指纹未变则不重绘；每秒的状态更新只在文字/颜色变化时改动视图，避免界面抖动。
- 读通道有请求时，顶部刷新图标旋转。


## 3.7.2 动效与触感（参考 emilkowalski/skills）

只取适用于原生 Views 的规则，不加装饰性动画。

- 统一强 ease-out 曲线 cubic-bezier(0.23, 1, 0.32, 1)，界面动画不超过 300ms，不用 ease-in。
- 按压反馈：按下 100ms 缩小，松开 160ms 回弹。普通按钮 0.97，通栏行入口 0.985，底部导航 0.94，图标按钮 0.9。禁用按钮无反馈。
- 详情页进入、返回：220ms 透明度 + 24dp 横向滑入，进入从右、返回从左。主导航切换每天很多次，保持即时、无过渡。
- 底部导航选中块沿用 220ms，改用同一 ease-out 曲线；刷新转圈 700ms 一圈。
- 确认删除、重新部署、关机时触发一次确认触感（Android 11+ CONFIRM，更早版本 CONTEXT_CLICK）；其他操作不振动。
- 32sp 金额字距 -0.02em；中文标题不收紧字距。
- 系统“移除动画”开启时所有过渡时长为 0，状态即时到位。
